# Telegram-бот

aiogram 3, long polling (вебхук Telegram не нужен — входящий доступ из интернета не требуется).

## Доступ
Middleware `DbSessionAndAuthMiddleware` ищет пользователя по `telegram_id` в таблице `users`.
* Владелец (`ADMIN_TELEGRAM_ID`) создаётся автоматически и всегда получает роль `admin`.
* Остальных заводит `python -m app.users.seed` (из `PARTNER_*` в `.env`) или admin на странице `/users`.
* Незнакомцы получают «Доступ запрещён» со своим Telegram ID.

## Файлы
Любой документ, отправленный боту (`handlers/documents.py`), обрабатывается как выписка банка
(Сбер, Альфа, Т-Банк: PDF/CSV) или брокерский отчёт (CSV/XLSX/PDF) — та же логика, что и `/api/upload`.
Банковские операции сохраняются только после подтверждения. Без спорных совпадений подтвердить можно кнопкой
в Telegram; при совпадениях бот предлагает проверить каждую строку в веб-панели. Для входа — `/web`.
Предпросмотры хранятся в БД и доступны после перезапуска через `/imports` или страницу `/upload`.
Брокерские отчёты продолжают сохраняться сразу. [Правила импорта и отмены](statement-imports.md).

## Пуши от бота
* напоминания (каждую минуту проверка);
* недельная финансовая сводка (вс 18:00 МСК);
* новый вес из Home Assistant (+ опциональный дайджест админу без цифр);
* итоги питания за день (23:50).
* предложение вечерней прогулки в 20:00 по `ACTIVITY_TZ`, если `ACTIVITY_NUDGE_ENABLED=true`
  и сегодня получено менее `ACTIVITY_NUDGE_STEPS` шагов (по умолчанию 5000).
  Без сегодняшней записи пуш не отправляется; нулевые шаги в существующей записи учитываются.

## Ограничения
* Состояния диалогов (FSM) хранятся в памяти — после рестарта контейнера незавершённый диалог теряется.
* Ручного ввода веса в боте нет — только через Home Assistant или API.
